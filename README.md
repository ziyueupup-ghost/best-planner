# Best Planner

macOS 看板任务管理 App，带桌面小组件。

## 功能

- 自定义状态列（名称、emoji 图标、颜色、顺序、「完成列」、列宽：拖动右边缘或在列菜单里选，双击边缘恢复自动）
- 优先级可自定义（名称、颜色、emoji、顺序、默认值），卡片标题前显示优先级的 emoji 或彩色圆点
- 任务：备注、色条颜色和背景颜色、子任务、多个日期（截止 / 里程碑 / 开始 / 提醒）
- 标签：emoji 图案、19 种形状、8 种样式、7 种边框线条和 5 档粗细，文字 / 背景 / 边框颜色可分别设置；18 套颜色搭配和 14 个一键风格
- 每个状态可以单独设置折叠：整列折叠、按标签、按优先级、按日期（已完成列按完成日期）；分组顺序可以拖动分组标题或右键调整，每个状态单独记住
- 复制任务（右键菜单或编辑窗口的「复制」，可选清空子任务勾选）；副本放在原任务上面并自动打开编辑
- 多选任务（工具栏「选择」或 ⌘+单击）：一起移到其他状态、上移下移、移到最上最下、拖动、删除
- 左右箭头或拖拽移动任务；拖到另一张卡片上可调整顺序；多种排序方式；搜索、按标签筛选
- 子任务包：预设好的子任务清单，在任务里一键加入（加入后是任务自己的副本）；可以关联标签，加标签时自动加入；子任务可以用 ↑↓ 调整顺序
- 每个任务的历史记录（自动记录移动、完成、修改，带日期时间；也可以手动添加记录）
- 完成日期：进入「完成列」时自动记录，可以手动修改
- 字体大小可调（显示菜单 ⌘+ ⌘- ⌘0，或工具栏「Aa」选 85%–160%）
- 删除前会二次确认；删除的任务进入「最近删除」（文件菜单 ⇧⌘⌫），保留 30 天，可以恢复；列菜单里可以「清空这一列」
- 撤销 / 重做（编辑菜单 ⌘Z / ⇧⌘Z）
- 提醒通知：「提醒」日期到点通知，「截止」当天 9 点通知；每个任务可以单独关闭通知
- 重复任务：每天 / 工作日 / 每周 / 每两周 / 每月 / 每年，完成后自动生成下一次
- 快速添加：全局快捷键 ⌃⌥N 或菜单栏图标，识别「明天下午3点 #标签 !优先级 @状态」
- 日程视图：工具栏切换「看板 / 日程」，按日期看所有没完成的任务
- 专注计时（番茄钟）和统计：完成数量、专注时间、按标签
- 回顾：工具栏切到「回顾」，日历上按颜色深浅看每天做了多少，点某一天看完成了哪些任务和子任务、专注多久，还能写「今日总结」；连续打卡天数和 18 个成就
- 附件和链接：给任务添加文件、文件夹、网址，一键打开
- 检查更新（菜单「Best Planner → 检查更新…」，另外每天自动检查一次）
- iCloud 云盘同步（菜单「Best Planner → 使用 iCloud 云盘同步…」）：同一个 Apple ID 的几台 Mac 用同一份数据
- 每天自动备份，保留最近 30 天（菜单「Best Planner → 打开备份文件夹」）
- 所有修改自动保存
- 桌面小组件（小 / 中 / 大）：显示子任务，可以直接打勾完成任务和子任务

## 下载安装（给使用者）

1. 到本仓库的 **Releases** 页面下载最新的 `BestPlanner-版本号.zip`，解压后把 `Best Planner.app` 拖进「应用程序」文件夹。
2. **第一次打开会被 macOS 拦住**（提示无法验证开发者），这是因为这个 App 没有付费的苹果开发者签名：
   - 先双击打开一次，出现提示后点「完成」；
   - 打开「系统设置 → 隐私与安全性」，往下拉，点「仍要打开」，再确认一次。之后就能正常打开了。
3. 需要 macOS 14（Sonoma）或更新；苹果芯片和 Intel 的 Mac 都可以用。
4. 桌面小组件：在桌面空白处右键 →「编辑小组件」→ 搜索「Best Planner」。
5. 以后在菜单「Best Planner → 检查更新…」里就能看到有没有新版本。

每个人的数据都保存在自己电脑上（`~/Library/Application Support/Planner/`），开了 iCloud 同步的话放在 iCloud 云盘的 `Best Planner` 文件夹。

## 编译安装（给开发者）

只需要系统自带的 Command Line Tools，不需要 Xcode：

```bash
./build.sh
```

会编译并安装到 `/Applications/Best Planner.app`。

发布新版本：改 `build.sh` 里的 `VERSION`，然后

```bash
./build.sh release
```

会在 `dist/` 里生成通用版（苹果芯片 + Intel）的 zip，上传到 GitHub Releases（标签写成 `v版本号`），大家的「检查更新」就能看到。

## 文件

| 路径 | 内容 |
|---|---|
| `Shared/Models.swift` | 数据模型、读写、App 和小组件共用的视图 |
| `App/` | 主程序界面和数据存储 |
| `Shared/` 其他文件 | 标签样式、折叠分组、历史记录、批量移动、重复任务、日程、回顾和成就、快速添加解析、字体大小 |
| `App/` 其他文件 | 编辑窗口、设置、最近删除、日程视图、回顾视图、统计、专注计时、提醒通知、快速添加、附件、检查更新 |
| `Widget/PlannerWidget.swift` | 桌面小组件 |
| `Widget/WidgetIntents.swift` | 小组件上的打勾按钮 |
| `Resources/make_icon.swift` | 生成 App 图标 |
| `Resources/make_intents_metadata.py` | 生成小组件打勾按钮需要的 App Intents 元数据 |
| `build.sh` | 编译、签名、安装 |

数据保存在 `~/Library/Application Support/Planner/planner.json`。

## 注意

- 小组件必须用 `-e _NSExtensionMain` 链接（`build.sh` 里已经写好），否则系统会认不出它，组件一启动就退出。
- 小组件上的打勾按钮靠 `Metadata.appintents` 让系统认识。Xcode 会自动生成，这里没有 Xcode，由 `make_intents_metadata.py` 生成；改了 `Widget/WidgetIntents.swift` 里的名字或参数，要同步改这个脚本。
- App 用的是本机签名（ad-hoc），只能在这台电脑上运行。
